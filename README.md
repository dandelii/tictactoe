# Tic Tac Toe
There isn't much to say about this project. It's tic tac toe, I think we all know how to play tic tac toe at this point. You're the *X*, opponent/computer is the *O*.  

There's a semi-smart algorithmn built in to tell the computer what a smart play will be, but to make it a little less boring and predictable, there's a "play dumb" feature where the computer has a 20% chance every turn of ignoring a smart move and selecting a random square instead.
